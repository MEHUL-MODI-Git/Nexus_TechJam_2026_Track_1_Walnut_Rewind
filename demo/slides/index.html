Evidence & authorization middleware for AI agents. It controls what an agent is allowed to know, proves what it actually knew, and repairs the damage when a source turns out to be wrong.

The problem

An agent will act on whatever reaches its context.

  • Restricted data sits next to useful data. Nothing stops a payroll file from leaking into a launch-planning prompt — and nothing proves it didn't.
  • Facts change. A launch date slips; yesterday's runs silently disagree with today's, and the agent picks one without telling anyone.
  • Sources get compromised. When a trusted input turns out tampered, nobody can say which decisions were built on it — or what to rebuild.

Logs tell you what an agent did. Nothing tells you what it was allowed to know, why it believed it, and what to do when the belief goes bad.

What we built · additive middleware, four modules

The model proposes. The middleware verifies, authorizes, and records.

  • Evidence runtime — every run gets a hash-chained, redact-before-persist flight recorder; evidence proposals only become evidence after an exact byte-match against their source.
  • Context & authorization — grants are checked before the prompt is built; the run executes against a sealed Context Capsule; agent-to-agent shares are re-authorized on both legs.
  • Dependency & rewind — a projected graph links evidence → capsules → runs → artifacts; compromise triggers a precise blast radius; recovery is a new run, never an edit.
  • Platform — REST surface + four drawer tabs in the existing UI, rendering live backend state.

Proof 1 · authorization before context (live in the demo)

The denied payroll data never reached the model.

  • A planted canary rides in the restricted payroll claim. After the Strategy run: 0 occurrences in the rendered prompt, 0 in the sealed capsule, 0 in the run's ledger chain — while remaining present in the evidence store. Stored ≠ rendered.
  • The DENY is a first-class record: reason AGENT_SCOPE_MISSING, decision id, policy revision + hash.
  • The delegation ceiling holds too: an agent sharing on behalf of a human is capped by that human's authority — DENY · PRINCIPAL_SCOPE_MISSING, enforced in the two-leg evaluator, no UI involved.

Proof 2 · evidence you can check, not vibes

A citation is bytes, or it is rejected.

  • Every claim must quote its source and the quote must satisfy source[start:end] === quote. In the demo, the model's third proposal fails by a few bytes → rejected, citation_mismatch, with the exact range in the ledger — regardless of model confidence.
  • Every runtime event we observe — commands, file changes, model steps — lands in a hash-chained, redacted ledger. Corrupt a copy at any sequence and verification answers ok:false · brokenAtSequence · hash_mismatch — while the real chain stays intact.
  • Secrets are redacted before persistence — proven with planted canaries for an API key, bearer token, private key, and env values.
Measured: rejection event with byte range content[28:61] (results/p3-walkthrough-rehearsal.md §B1) · tamper: brokenAtSequence pinpointed (both rehearsals)
Proof 3 · when a source goes bad

Precise blast radius. Selective recovery. History stays append-only.

  • Compromising one launch claim flagged exactly the two runs and one artifact built on it — an unrelated earlier run was not re-flagged. Precision, not blanket invalidation.
  • Rewind = a brand-new run with a fresh capsule (the bad claim now status-denied). The old run becomes RECOVERED, linked RECOVERED_BY — its capsule hash and event chain byte-identical after recovery.
  • Conflicting evidence never gets a silent pick: the run is blocked before any model call — a typed clarification request, at a measured cost of 0 model tokens.

Honest limitations · stated, because that is the product

What we deliberately do not claim.

  • The runtime stream is Codex-emitted events, not complete provider telemetry — we do not claim every physical model request/retry is observed, and JSONL is not a pre-command enforcement boundary.
  • The Docker container is an isolation convenience, not a hardened multi-tenant sandbox; the grant model is hackathon-scale, not production OAuth.
  • Redaction ≠ anonymization; hash chaining proves recorded history is intact — not that an unobserved action never happened.
  • The evidence-pack export was cut, not stubbed — it is absent and documented as such.
